# Xzor app

Clean starter app using [Xzor](https://github.com/pedro-gilmora/source-crafter-xzor), with Tailwind CSS loaded from its CDN.

## Run locally

```sh
bun install
bun run dev
```

The app is mounted at `/`. Add pages in `src/pages`, shared components in `src/components`, and application logic in `src`.
